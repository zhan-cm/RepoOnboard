This revision is the V0.1 demo target because it is public, has an explicit
license, and provides enough real structure to exercise Repository Overview,
Architecture Workspace, API Map, and Start Here in one run. It has meaningful
confirmed relationships without the scale and UI density of the ThingsBoard
boundary trial.

RepoOnboard links to and analyzes the upstream repository in place. It does not
copy the target into this repository, build or run the target application, or
modify its files. If the upstream project is redistributed separately, its
license and notices remain authoritative.

## Reproducible checkout

Run these commands from a RepoOnboard source checkout after completing the
README build instructions. The demo and an intentionally empty Maven model
cache are created under the ignored `target/demo/` directory.

Windows PowerShell:

```powershell
New-Item -ItemType Directory -Force .\target\demo | Out-Null
git init .\target\demo\jhipster-sample-app
git -C .\target\demo\jhipster-sample-app remote add origin https://github.com/jhipster/jhipster-sample-app.git
git -C .\target\demo\jhipster-sample-app fetch --depth 1 origin e06e87abe0be8a3a194381ce651164a734811b3f
git -C .\target\demo\jhipster-sample-app checkout --detach FETCH_HEAD
git -C .\target\demo\jhipster-sample-app rev-parse HEAD
New-Item -ItemType Directory -Force .\target\demo\empty-maven-repository | Out-Null
.\repoonboard.cmd .\target\demo\jhipster-sample-app --local-repository .\target\demo\empty-maven-repository --no-open
```

macOS or Linux:

```bash
mkdir -p target/demo
git init target/demo/jhipster-sample-app
git -C target/demo/jhipster-sample-app remote add origin https://github.com/jhipster/jhipster-sample-app.git
git -C target/demo/jhipster-sample-app fetch --depth 1 origin e06e87abe0be8a3a194381ce651164a734811b3f
git -C target/demo/jhipster-sample-app checkout --detach FETCH_HEAD
git -C target/demo/jhipster-sample-app rev-parse HEAD
mkdir -p target/demo/empty-maven-repository
./repoonboard target/demo/jhipster-sample-app --local-repository target/demo/empty-maven-repository --no-open
```

`rev-parse HEAD` must print exactly:

```text
e06e87abe0be8a3a194381ce651164a734811b3f
```

Open the printed `http://127.0.0.1:<port>/` address. Keep the terminal running
while using the UI, then press Ctrl+C to stop RepoOnboard. The empty model cache
is deliberate: it makes missing upstream parent metadata and the resulting
`PARTIAL` coverage reproducible instead of depending on one developer's Maven
cache.

## Four-page walkthrough

### 1. Repository Overview

Confirm the `PARTIAL` badge and the project identity
`io.github.jhipster.sample:jhipster-sample-application:0.0.1-SNAPSHOT`. The page
should report one module, 81 source files, 30 components, and 24 endpoints.
Open the diagnostics summary to show that incomplete coverage is explicit.

### 2. Architecture Workspace

Keep the root module selected and filter to REST Controller, Service, and
Repository. The report contains seven confirmed edges, including:

```text
bankAccountResource → bankAccountRepository
operationResource → operationRepository
labelResource → labelRepository
userService → authorityRepository
userService → userRepository
```

Select `userService` and turn `1-hop` on. The focused scope should show
`userService`, `authorityRepository`, and `userRepository` with two confirmed
edges. Unresolved counts remain visible; they are not drawn as facts.

### 3. API Map

Search for `/api/bank-accounts`. Six endpoints should match:

```text
GET     /api/bank-accounts
POST    /api/bank-accounts
GET     /api/bank-accounts/{id}
PUT     /api/bank-accounts/{id}
PATCH   /api/bank-accounts/{id}
DELETE  /api/bank-accounts/{id}
```

Select `POST /api/bank-accounts` to show the `createBankAccount` handler, its
repository-relative source location, and method/class mapping Evidence.

### 4. Start Here

The page should show 10 of 24 recommendations by default and retain the partial
coverage notice. The first two items are:

```text
1. pom.xml
   Reason: Root Maven build file

2. src/main/java/io/github/jhipster/sample/JhipsterSampleApplicationApp.java
   Reasons: Application entry point; Configuration component
```

Use `Show 14 more recommended files` to expand the list to all 24 items and
demonstrate that the default list is progressive
disclosure rather than discarded results. The reason text and source Evidence
must be visible; no AI-generated explanation is involved.
